# Frontend feature parity audit

Audit basis: source review and a live same-origin browser tour on 2026-10-13. The active navigation has 22 view IDs in `frontend/src/lib/navigation.ts`. Activity is reachable at `?view=dashboard&activity=1`; legacy `?view=dashboard` opens the conversation-first Chat home. Earlier route checks predate the removal of the PhD studio and do not verify this build.

Status meanings: **Implemented (source)** means a screen, API calls, and listed actions are visible in source; **Partial** means a route exists but dossier-level interaction/visual/feature details are absent or generic; **Unverified** means runtime/backend/browser behavior was not demonstrated in this audit. No item below is a release PASS.
