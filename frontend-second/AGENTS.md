# Frontend work priorities

- For frontend tasks, prioritize completing the full experience for desktop and laptop screens first because the user primarily works on a laptop.
- Finish desktop screen layouts, interactions, states, and visual fidelity before spending time on mobile-specific layouts or polish.
- Include mobile/device layouts when the active request explicitly names mobile viewport sizes or asks for mobile verification; the current visual acceptance request explicitly requires 390px and 768px checks.
- Preserve the approved frontend design on desktop while following this priority.
